## Useful details for a bug report

<p class="zh">回報問題時請附上</p>

| Include                                   | 請附上                        |
| ----------------------------------------- | ----------------------------- |
| Tool version (Help → About)               | 工具版本（說明 → 關於）       |
| AEDT version                              | AEDT 版本                     |
| What you did, what you expected, what happened | 操作步驟、預期結果、實際結果 |
| Screenshot with paths and board names hidden | 截圖（遮住路徑與板名）     |

**Do not attach design files, logs with file paths, or customer data.** If we need more, we will arrange a secure
channel through TADC.

<p class="zh">**請勿附上設計檔、含檔案路徑的 log 或客戶資料。** 需要更多資料時，會透過 TADC 另行安排安全的傳送方式。</p>

Public, non-confidential issues can also be filed on the
[public repository's issue tracker](https://github.com/ovo0615/pcb-si-3d-simulation-toolkit/issues) — anything posted
there is visible to everyone.

<p class="zh">不涉機密的問題也可以在公開 repo 的 Issues 回報；張貼的內容所有人都看得到。</p>

## How your data is used

<p class="zh">資料用途</p>

Feedback is used only to fix problems, plan improvements and reply to you. It is stored in TADC's Microsoft 365 and is
never published. This site stores nothing and uses no tracking. Contact: Jeff Hong 洪敬傑, TADC —
[jeff.hong@cadmen.com](mailto:jeff.hong@cadmen.com).

<p class="zh">回饋只用於修正問題、規劃改進與回覆你；存放在虎門科技的 Microsoft 365，不會公開。本網站不儲存資料、不做追蹤。</p>
