## System requirements · 系統需求

| Component | Purpose and requirement | 用途與需求 |
| --- | --- | --- |
| Windows 10/11 x64 | Tool host | 工具執行環境 |
| Ansys Electronics Desktop 2026 R1 | Simulation; the relevant Ansys licences are required separately | 求解環境；各功能需另備相應的 Ansys 授權 |
| Microsoft Edge WebView2 Runtime | Tool window; install it if the installer prompts you | 顯示工具視窗；缺少時依安裝程式提示安裝 |
| Runtime components | Python 3.12 and offline packages are bundled in the v1.0.4 installer; no separate installation required | v1.0.4 安裝包內附 Python 3.12 與離線套件，不需另裝 Python、Node.js 或 pip 套件 |

Use the installation guide supplied with your delivered version. Do not assume other AEDT versions are supported. Node.js is not required for normal use of the complete package.

<p class="zh" lang="zh-Hant">安裝需求依交付版本隨附的安裝說明確認。其他 AEDT 版本的支援情況需另行確認；一般使用完整工具包不需 Node.js。</p>

## Licensing & trial · 授權與試用

The complete tool, commercial licensing and support are provided through TADC. From v1.0.4, the trial lasts 14 days and is bound to one computer. Confirm the delivered version and licence expiry. This tool does not include, provide or bypass Ansys licensing.

<p class="zh" lang="zh-Hant">完整工具、商用授權與支援由虎門科技提供。v1.0.4 起試用 14 天、單機綁定；請確認交付版本與授權到期時間。本工具不含、不提供亦不繞過 Ansys 授權。</p>
