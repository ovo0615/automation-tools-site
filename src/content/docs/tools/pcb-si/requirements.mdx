## System requirements · 系統需求

| Component | Purpose and requirement | 用途與需求 |
| --- | --- | --- |
| Windows 10/11 x64 | Tool host | 工具執行環境 |
| Ansys Electronics Desktop 2026 R1 | Simulation; the relevant Ansys licences are required separately | 求解環境；各功能需另備相應的 Ansys 授權 |
| Python 3.12 x64 | Complete-package runtime; the launcher can install it | 完整工具包的執行環境；啟動器可安裝 |
| Python dependencies | `fastapi` (local service), `pyedb` (layout), `pyaedt` (AEDT), `scikit-rf` (Touchstone), `pywebview` (desktop window); installed by the launcher using locked versions | 本機服務、Layout、AEDT、Touchstone 與桌面視窗；啟動器依鎖定版本安裝 |
| Microsoft Edge WebView2 Runtime | Embedded desktop window; the documented fallback is an external browser | 桌面內嵌視窗；缺少時可退回外部瀏覽器 |

The maintained prerequisite list and optional feature dependencies are in the [public README](https://github.com/ovo0615/pcb-si-3d-simulation-toolkit/blob/main/README.en.md#complete-tool-prerequisites). Do not assume other AEDT versions are supported. Node.js is not required for normal use of the complete package.

<p class="zh" lang="zh-Hant">完整前置需求及選用功能套件以公開 README 為準。其他 AEDT 版本的支援情況需另行確認；一般使用完整工具包不需 Node.js。</p>

The complete tool, commercial licensing and support are provided through TADC. Trial duration and machine-binding terms must be confirmed with the supplied package. This tool does not include, provide or bypass Ansys licensing.
