Extract and solve a PCB signal channel, cascade its segments, and inspect S-parameters, TDR locations and an
HTML report — driving Ansys HFSS 3D Layout, SIwave and Circuit through PyAEDT and PyEDB.

<p class="zh">
  PCB SI 3D 模擬分析工具：從 PCB 裁出訊號通道並求解、串接各段，再看 S 參數、TDR 定位與 HTML 報告；透過 PyAEDT 與 PyEDB 驅動
  Ansys HFSS 3D Layout、SIwave 與 Circuit。
</p>

## What it does

<p class="zh">主要功能</p>

| Task                                                                 | 功能                                          |
| -------------------------------------------------------------------- | --------------------------------------------- |
| Net selection and cutout of the signal channel                       | 選訊號網路、裁出通道                          |
| Endpoint ports; automatic sweep from the maximum frequency           | 元件端 Port；依最高頻率自動產生掃頻           |
| Whole-board or segmented analysis with A–F cut-plane grading         | 整片或分段求解，切面 A～F 評級                |
| Per-segment HFSS / SIwave, scheduled solving with adjustable cores   | 逐段指定 HFSS／SIwave，排程求解、核心數可調   |
| Touchstone cascading of all-SIwave or all-HFSS segments              | 全部 SIwave 或全部 HFSS 的分段串接            |
| S-parameter viewer with exact readout and Excel export               | S 參數檢視、雙擊讀值、匯出 Excel              |
| TDR mapped back to the Layout                                        | TDR 阻抗定位並標回 Layout                     |
| IBIS model library                                                   | IBIS 模型庫                                   |
| Single-file HTML report with snapshots                               | 一鍵單檔 HTML 報告                            |

Some features are **Beta**: usable, with fewer validation cases. They appear only after you tick **「啟用 Beta 功能」**, which applies to the current session only. Beta includes eye-diagram analysis, cross-section impedance (Q2D), cascading mixed HFSS and SIwave segments, stack-up change, backdrill and Layout cleanup. See the <Link to="/tools/pcb-si/manual/">quick start · 快速開始</Link> for the documented workflow.

<p class="zh">部分功能屬 Beta：可以使用，但驗證案例較少；要勾「啟用 Beta 功能」才出現，且只對本次啟動有效。Beta 包含眼圖分析、截面阻抗（Q2D）、HFSS 與 SIwave 混合串接、疊構更換、背鑽與 Layout 清理。已整理的步驟見快速開始。</p>

## Requirements

<p class="zh">系統需求</p>

Windows 10/11 x64, Microsoft Edge WebView2 Runtime, and Ansys Electronics Desktop 2026 R1 with the licences each feature needs. The installer bundles Python and every package; no separate installation is required. See <Link to="/tools/pcb-si/requirements/">requirements · 系統需求</Link>.

<p class="zh">
  Windows 10／11 64 位元、Microsoft Edge WebView2 Runtime、Ansys Electronics Desktop 2026 R1 與各功能所需授權。安裝包已內附 Python 與所需套件，不需另裝。
</p>

The tool does not include, provide or bypass Ansys licensing.

<p class="zh">本工具不含、不提供亦不繞過 Ansys 授權。</p>

## How to get it

<p class="zh">如何取得</p>

The complete tool, commercial licensing and technical support are provided through Taiwan Auto-Design Co. (TADC).
Simulation services and technical engagements are carried out through TADC using company-provided Ansys resources and
licences. The [public repository](https://github.com/ovo0615/pcb-si-3d-simulation-toolkit) contains front-end assets,
documentation and demonstration data only; it cannot run the complete workflow.

<p class="zh">
  完整工具、商用授權與技術支援由虎門科技（TADC）提供；模擬服務與技術合作透過 TADC、使用公司提供的 Ansys
