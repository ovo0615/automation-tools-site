## Local processing · 本機處理

The tool's simulation workflow runs locally; you do not need to upload design files to this website. Installation and dependency downloads may require an internet connection.

<p class="zh" lang="zh-Hant">工具的模擬流程在本機執行，不需要將設計檔上傳到此網站。安裝及下載相依套件可能需要網路連線。</p>

## Support packages · 支援包

Support packages contain diagnostic information, not models, EDB, Touchstone or simulation results. Diagnostic text may still contain sensitive paths, names, tokens or licence information. Inspect `manifest.json` and all included files before sharing.

<p class="zh" lang="zh-Hant">支援包含診斷資訊，不含模型、EDB、Touchstone 或求解結果；診斷文字仍可能含敏感路徑、名稱、token 或授權資訊，分享前須檢查 `manifest.json` 與所含檔案。</p>

## This website & external services · 網站與外部服務

This static site has no feedback database or analytics. Requests sent through Microsoft Forms or email are handled in TADC's Microsoft 365 for support, improvement planning and replies. Contact the support address to request access, correction or deletion. Do not send customer designs.

<p class="zh" lang="zh-Hant">此靜態網站沒有回饋資料庫或流量分析。Microsoft Forms 與 Email 由虎門科技的 Microsoft 365 處理，用於支援、改進規劃與回覆；查詢、更正或刪除資料請聯絡支援信箱。請勿傳送客戶設計檔。</p>

GitHub hosts this site and its linked public documentation and images. YouTube is contacted only when you play a video or open its external link. These services apply their own privacy policies.

<p class="zh" lang="zh-Hant">網站及連結的公開文件、圖片由 GitHub 提供；播放影片或開啟影片連結時才連至 YouTube。各服務適用其自身隱私政策。</p>
