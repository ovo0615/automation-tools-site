## First run in four steps · 四步開始

| Step | Action | 操作 |
| --- | --- | --- |
| 1 | Obtain the complete package or request a trial above. | 取得完整工具包，或由上方申請試用。 |
| 2 | Check Windows, AEDT, Python and licence requirements below. | 核對下方系統與授權需求。 |
| 3 | Extract the complete package and run `web_app/start.bat`. Allow the first dependency installation to finish. | 解壓完整工具包，執行 `web_app/start.bat`，等待首次相依套件安裝完成。 |
| 4 | Follow the public manual with non-confidential example data: import a board, select nets, preview a cutout, then configure ports and solve. | 依公開手冊使用不涉機密的範例資料：匯入板檔、選網路、預覽裁切，再設定 Port 與求解。 |

<Link to="/tools/pcb-si/requirements/">Requirements & trial · 系統需求與試用</Link> · <Link to="/tools/pcb-si/manual/">Open the manual · 操作說明</Link>

Detailed instructions and example prerequisites are in the [first-run manual](https://github.com/ovo0615/pcb-si-3d-simulation-toolkit/blob/main/docs/manual/00-第一次跑.md).

<p class="zh" lang="zh-Hant">首次操作的詳細步驟與範例需求以公開手冊為準；未完成 Port 與授權檢查前，先停在預覽。</p>
