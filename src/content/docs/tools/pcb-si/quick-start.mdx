## Before you begin · 開始前

| Required component | Purpose · 用途 |

## 1. Install · 安裝

Check the installer filename against `SHA256SUMS.txt`. Run this command in PowerShell from the delivery folder and compare the complete SHA-256 value. Use the filename for your delivered version.

<p class="zh" lang="zh-Hant">在交付資料夾用 PowerShell 核對 SHA-256，整串數值須與附檔一致。下例檔名對應實拍版本；收到其他版本時改用該版檔名。</p>

```powershell
Get-FileHash ./PCBSI-Setup-v1.0.3.exe -Algorithm SHA256
```

<ManualShot file="19-S02_received_files.png" alt="Four delivery files including the installer and SHA256SUMS.txt" caption="Check that all delivery files are present." zh="核對安裝檔、雜湊清單、安裝說明與授權文件。" />

<ManualShot file="19-S16_hash_check.png" alt="PowerShell SHA256 output and matching checksum file, with local paths removed" caption="Compare the complete hash for the same installer version." zh="核對同一版安裝檔的完整雜湊值；圖中路徑已遮蔽。" />

This unsigned version displays Windows SmartScreen. Proceed only after confirming the package came from TADC and its hash matches. Select **「其他資訊」**, then **「仍要執行」**. If the source or hash is uncertain, stop and contact support.

<p class="zh" lang="zh-Hant">實拍版本未數位簽章。確認來源為虎門科技且雜湊一致後，才按「其他資訊」→「仍要執行」。來源或雜湊有疑問時，停止安裝並聯絡支援。</p>

<ManualShot file="19-S17a_smartscreen.png" alt="Windows SmartScreen showing its information link" caption="Open the SmartScreen details." zh="按「其他資訊」查看安裝程式資訊。" />

<ManualShot file="19-S17b_smartscreen_run_anyway.png" alt="Windows SmartScreen with the 仍要執行 button" caption="Continue only after verifying the source and hash." zh="來源與雜湊核對無誤後，按「仍要執行」。" />

Read the licence agreement and decide whether to accept it. The desktop shortcut is optional. Check **「準備安裝」**, select **「安裝」**, and wait for completion. Use ASCII-only installation and working paths, including every parent folder.

<p class="zh" lang="zh-Hant">閱讀授權合約，自行決定是否同意；桌面捷徑為選用。在「準備安裝」核對後按「安裝」，等待完成。安裝與工作資料夾的完整路徑均使用英文字母、數字、底線或連字號。</p>

<ManualShot file="19-S05_select_folder.png" alt="Installer 準備安裝 page and 安裝 button, with destination path removed" caption="Review the destination before installing." zh="核對目的資料夾後按「安裝」；圖中完整路徑已遮蔽。" />

## 2. First launch · 首次啟動

Launch the tool from the Windows Start menu. Wait for startup without opening it again. At the task picker, select the tasks you need and press **「開始」**. Check the version under **「說明」→「關於本工具」**.

<p class="zh" lang="zh-Hant">從 Windows 開始功能表啟動，等待完成，不要重複開啟。在任務入口勾選項目，按「開始」；由「說明」→「關於本工具」確認版本。</p>

<ManualShot file="19-S01_task_picker.png" alt="PCB SI task picker with preparation, analysis and results tasks and the 開始 button" caption="Choose the tasks needed for this session." zh="任務入口分為準備、前處理（Beta）、分析與結果。" />

## 3. Check Ansys licences · Ansys 授權對照

Open **「說明」→「Ansys 授權對照與可用數量」**. The dialog is titled **「Ansys 授權對照與目前可用數量」**. The upper section handles the PCB SI product licence; the lower section maps Ansys functions to products. These licences are separate.

<p class="zh" lang="zh-Hant">開啟「說明」→「Ansys 授權對照與可用數量」，視窗標題為「Ansys 授權對照與目前可用數量」。上方是 PCB SI 產品授權，下方是 Ansys 功能與產品對照，兩者須分開準備。</p>

<ManualShot file="19-S07a_help_menu.png" alt="說明 menu with the Ansys licence comparison entry" caption="Open the licence comparison from Help." zh="從「說明」進入 Ansys 授權對照。" />

<ManualShot file="19-S11_ansys_license_table.png" alt="Ansys licence mapping showing only function and product columns" caption="Match the required function to its Ansys product." zh="依功能核對 Ansys 產品；圖中不顯示 feature 名稱與可用數量。" />

## 4. Export a request · 匯出授權申請檔

In **「PCB SI 產品授權」**, select **「匯出授權申請檔」**, choose a save location and send the request file to the trial contact. Export it on the computer that will run the tool; the licence is bound to that machine.

<p class="zh" lang="zh-Hant">在「PCB SI 產品授權」按「匯出授權申請檔」，選擇存放位置，再將申請檔寄給試用窗口。請在實際使用的電腦匯出，授權綁定該台電腦。</p>

<ManualShot file="19-S09a_import_button.png" alt="PCB SI product licence panel with 匯出授權申請檔 and 瀏覽並匯入授權檔" caption="Export the request from the product licence section." zh="產品授權區提供申請檔匯出與授權檔匯入。" />

## 5. Import the licence · 匯入授權檔

After receiving the licence, use **「瀏覽並匯入授權檔」→「選擇檔案」** in the same panel. Wait for verification, then check the licence name and UTC expiry time. Existing data can still be viewed and saved after expiry.

<p class="zh" lang="zh-Hant">收到授權檔後，在同一區的「瀏覽並匯入授權檔」按「選擇檔案」。等待驗證，確認授權名稱及到期時間（UTC）；到期後仍可存檔與查看既有資料。</p>

From **v1.0.4**, the trial lasts **14 days** and is bound to one computer. The screenshots document the earlier v1.0.3rc interface; confirm the delivered package and licence expiry.

<p class="zh" lang="zh-Hant">**v1.0.4 起試用 14 天、單機綁定。** 圖片記錄 v1.0.3rc 介面；實際交付版本與到期時間請依工具包及授權檔確認。</p>
