## Before you begin · 開始前

| Required component | Purpose · 用途 |
| --- | --- |
| Windows 10／11 x64 | Tool host · 工具執行環境 |
| Microsoft Edge WebView2 Runtime | Tool window; install it if the installer prompts you · 顯示工具視窗；缺少時依安裝程式提示安裝 |
| Ansys Electronics Desktop 2026 R1 and relevant licences | Layout preparation and simulation · Layout 前處理與求解；Ansys 授權另備 |
| Complete installer, `SHA256SUMS.txt`, installation guide and licence document | Obtain the complete delivery from TADC · 向虎門科技取得完整交付檔 |

Python and the required packages are bundled. Node.js is not required.

<p class="zh" lang="zh-Hant">安裝包已內附 Python 與離線套件，不需另裝 Python、Node.js 或 pip 套件。</p>

## 1. Install · 安裝

Check the installer against `SHA256SUMS.txt`. Run this command in PowerShell from the delivery folder and compare the complete SHA-256 value.

<p class="zh" lang="zh-Hant">在交付資料夾用 PowerShell 核對 SHA-256，整串數值須與附檔一致。</p>

```powershell
Get-FileHash ./PCBSI-Setup-v1.0.4.exe -Algorithm SHA256
```

The installer screens below were captured from an earlier delivery; the steps are the same for v1.0.4.

<p class="zh" lang="zh-Hant">以下安裝畫面取自前一版交付包，v1.0.4 步驟相同；檔名請以實際收到的版本為準。</p>

<ManualShot file="19-S16_hash_check.png" alt="PowerShell SHA256 output and matching checksum file, with local paths removed" caption="Compare the complete hash for the same installer version." zh="核對同一版安裝檔的完整雜湊值；圖中路徑已遮蔽。" />

The installer is not digitally signed, so Windows SmartScreen may appear. Proceed only after confirming the package came from TADC and its hash matches: select **「其他資訊」**, then **「仍要執行」**. If the source or hash is uncertain, stop and contact support or your IT team.

<p class="zh" lang="zh-Hant">安裝程式未數位簽章，可能出現 SmartScreen。確認來源為虎門科技且雜湊一致後，才按「其他資訊」→「仍要執行」。來源或雜湊有疑問時，停止安裝並聯絡支援或公司 IT。</p>

<ManualShot file="19-S17a_smartscreen.png" alt="Windows SmartScreen showing its information link" caption="Open the SmartScreen details." zh="按「其他資訊」查看安裝程式資訊。" />

<ManualShot file="19-S17b_smartscreen_run_anyway.png" alt="Windows SmartScreen with the 仍要執行 button" caption="Continue only after verifying the source and hash." zh="來源與雜湊核對無誤後，按「仍要執行」。" />

Read the licence agreement and third-party notices; an authorised person decides whether to accept. Check **「準備安裝」**, select **「安裝」**, and wait for completion. Use ASCII-only installation and working paths, including every parent folder.

<p class="zh" lang="zh-Hant">閱讀授權合約與第三方授權聲明，由有權人員決定是否同意。在「準備安裝」核對後按「安裝」，等待完成。安裝與工作資料夾的完整路徑均使用英文字母、數字、底線或連字號。</p>

## 2. First launch · 首次啟動

Launch the tool from the Windows Start menu and wait for startup without opening it again. At the task picker, select the tasks you need and press **「開始」**. **「只選主要功能」** selects every non-Beta task.

<p class="zh" lang="zh-Hant">從 Windows 開始功能表啟動，等待完成，不要重複開啟。在任務入口勾選這次要用的項目，按「開始」；「只選主要功能」會勾選所有非 Beta 項目。</p>

<ManualShot file="v104-qs01-task-picker.webp" alt="v1.0.4 task picker with preparation, analysis and results tasks, the Beta switch and the 開始 button" caption="Choose the tasks for this session. Change them later with 調整項目." zh="任務入口分為準備、前處理、分析與結果；之後可按「調整項目」改。" />

The **「啟用 Beta 功能」** checkbox is off at every launch and applies only to the current session. Beta features are usable but have fewer validation cases.

<p class="zh" lang="zh-Hant">「啟用 Beta 功能」每次啟動預設關閉，勾選只對本次啟動有效。Beta 功能可以使用，但驗證案例較少。</p>

## 3. Check Ansys licences · Ansys 授權對照

Open **「說明」→「Ansys 授權對照與可用數量」**. Check the version under **「說明」→「關於本工具」**.

<p class="zh" lang="zh-Hant">開啟「說明」→「Ansys 授權對照與可用數量」；版本由「說明」→「關於本工具」確認。</p>

<ManualShot file="v104-qs07-help-menu.webp" alt="說明 menu with 關於本工具, Ansys 授權對照與可用數量 and 產生支援包" caption="Licence comparison, version and support package are under Help." zh="「說明」選單：關於本工具、Ansys 授權對照、產生支援包。" />

The dialog has two parts: **「PCB SI 產品授權」** for this tool, and a table mapping each function to the Ansys product it needs. The two licences are separate.

<p class="zh" lang="zh-Hant">視窗分兩部分：上方「PCB SI 產品授權」是本工具的授權；下方對照每個功能需要的 Ansys 產品。兩者須分開準備。</p>

<ManualShot file="v104-qs11-license-table.webp" alt="Function and Ansys product columns of the licence comparison table" caption="Match each function to its Ansys product." zh="依功能核對 Ansys 產品；圖中只保留功能與產品兩欄。" />

## 4. Export a request · 匯出授權申請檔

In **「PCB SI 產品授權」**, select **「匯出授權申請檔」**, choose a save location and send the file to the trial contact. Export it on the computer that will run the tool; the licence is bound to that machine.

<p class="zh" lang="zh-Hant">在「PCB SI 產品授權」按「匯出授權申請檔」，選擇存放位置，再依約定管道寄給試用窗口。請在實際使用的電腦匯出，授權綁定該台電腦。</p>

<ManualShot file="v104-qs09-license-buttons.webp" alt="PCB SI product licence buttons: 匯出授權申請檔, 瀏覽並匯入授權檔, 匯出時鐘解鎖申請檔 and 瀏覽並匯入時鐘解鎖檔" caption="Export the request and import the licence in the same section." zh="同一區匯出申請檔、匯入授權檔；下方是時鐘解鎖。" />

## 5. Import the licence · 匯入授權檔

After receiving the licence, use **「瀏覽並匯入授權檔」→「選擇檔案」**. Wait for verification, then check the licence name and expiry time (UTC). The trial lasts **14 days** on one computer; the licence file defines the exact start and end. After expiry you can still save and view existing results.

<p class="zh" lang="zh-Hant">收到授權檔後，按「瀏覽並匯入授權檔」→「選擇檔案」，等待驗證，確認授權名稱與到期時間（UTC）。試用 **14 天**、單機綁定，起訖以授權檔為準；到期後仍可存檔與查看既有結果。</p>

If a wrong system clock blocks the tool, restore the correct time with automatic sync first. If it is still blocked, export **「匯出時鐘解鎖申請檔」** for the issuer.

<p class="zh" lang="zh-Hant">誤調時間被擋時，先改回正確時間並開自動對時；仍被擋再按「匯出時鐘解鎖申請檔」交給簽發者。</p>
