## Installation & runtime · 安裝與執行

| Question · 問題 | Confirmed guidance | 已確認的處理方式 |
| --- | --- | --- |
| Can I run the public Source ZIP? · 可以直接執行公開的 Source ZIP 嗎？ | It lacks the complete backend and launcher. Obtain the complete package through TADC. | 公開 ZIP 不含完整後端與啟動器，請向虎門科技取得完整工具包。 |
| Do I need to install Python? · 需要自行安裝 Python 嗎？ | No. The v1.0.4 installer bundles Python and offline packages. Install WebView2 only if the installer prompts you. | 不需要。v1.0.4 安裝包已內附 Python 與離線套件；只有安裝程式提示時才需安裝 WebView2。 |
| Startup has not finished. · 工具尚未啟動完成，該怎麼辦？ | Wait without launching another copy. Retain the exact error if startup fails. | 等待完成，不要重複開啟；若啟動失敗，保留完整錯誤。 |
| Which AEDT version? · 應使用哪個 AEDT 版本？ | The public prerequisites specify 2026 R1. Confirm compatibility before using another version. | 公開需求指定 2026 R1，其他版本請先確認相容性。 |

## Licences & solving · 授權與求解

| Question · 問題 | Confirmed guidance | 已確認的處理方式 |
| --- | --- | --- |
| Does the tool include Ansys licences? · 工具包含 Ansys 授權嗎？ | No. Arrange the licences required for your selected features separately. | 不含 Ansys 授權；各功能所需授權須另備。 |
| Should I select 4 cores immediately? · 一開始就應選擇 4 核心嗎？ | No. **「求解核心數」** defaults to 12 and can be changed; set 4 only when no HPC licence is available. If the licence server has no Pack-type HPC, SIwave uses the Workgroup pool at the same core count and HFSS is unaffected — that is not a shortage. Keep the original error for support. | 不需要。「求解核心數」預設 12、可調整；只有沒有 HPC 授權時才設 4。授權伺服器沒有 Pack 型 HPC 時，SIwave 以相同核心數改用 Workgroup（pool），HFSS 不受影響，這不代表授權不足。請保留原始錯誤供支援判讀。 |
| Where are trial terms? · 試用期限與條件是什麼？ | From v1.0.4 the trial lasts 14 days on one computer; the licence file defines the exact dates. | v1.0.4 起試用 14 天、單機綁定，起訖以授權檔為準。 |
