## Installation & runtime · 安裝與執行

| Question | Confirmed guidance | 已確認的處理方式 |
| --- | --- | --- |
| Can I run the public Source ZIP? | It lacks the complete backend and launcher. Obtain the complete package through TADC. | 公開 ZIP 不含完整後端與啟動器，請向虎門科技取得完整工具包。 |
| Do I need to install Python? | No. The v1.0.3 installer includes the required runtime components. | 不需要。v1.0.3 安裝包已含所需執行元件。 |
| Startup has not finished. | Wait without launching another copy. Retain the exact error if startup fails. | 等待完成，不要重複開啟；若啟動失敗，保留完整錯誤。 |
| Which AEDT version? | The public prerequisites specify 2026 R1. Confirm compatibility before using another version. | 公開需求指定 2026 R1，其他版本請先確認相容性。 |

## Licences & solving · 授權與求解

| Question | Confirmed guidance | 已確認的處理方式 |
| --- | --- | --- |
| Does the tool include Ansys licences? | No. Arrange the licences required for your selected features separately. | 不含 Ansys 授權；各功能所需授權須另備。 |
| Should I select 4 cores immediately? | HFSS defaults to 12 cores. Use 4 only after an explicit HPC or core-count licence error; keep the original error for support. | HFSS 預設 12 cores，僅遇明確 HPC 或核心授權錯誤才改 4 cores，並保留原始錯誤供支援判讀。 |
| Where are trial terms? | Confirm them with the complete package supplied by TADC. | 試用條件以虎門科技提供的完整工具包確認。 |
