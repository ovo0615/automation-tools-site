## Report details · 回報內容

| Detail | 內容 |
| --- | --- |
| Tool version, Windows version, AEDT version | 工具、Windows 與 AEDT 版本 |
| Numbered steps to reproduce | 可重現的操作步驟 |
| Expected result and actual result | 預期結果與實際結果 |
| Exact error and a redacted screenshot | 完整錯誤訊息與已遮蔽機密的截圖 |
| A reviewed support package, if available | 檢查過的支援包（若可產生） |

## Review the support package · 先檢查支援包

Choose **「說明」→「產生支援包（日誌與診斷）」**, as shown in this site's <Link to="/tools/pcb-si/manual/#support-package--支援包">support-package guide · 支援包說明</Link>. Packages are encrypted by default; also save a plain-text review copy and inspect its `manifest.json` and included files before sharing. The package excludes models, EDB, Touchstone and simulation results, but diagnostic text may still contain paths, names, tokens or licence information.

<p class="zh" lang="zh-Hant">由「說明」→「產生支援包（日誌與診斷）」匯出。預設支援包加密；另存明文審閱版，檢查 `manifest.json` 與所含檔案後才分享。支援包排除模型、EDB、Touchstone 與求解結果，但診斷文字仍可能含路徑、名稱、token 或授權資訊。</p>

**Do not upload customer designs, confidential data or an unchecked support package.** If you cannot safely remove sensitive details, email only the redacted steps and ask how to proceed.

<p class="zh" lang="zh-Hant">**不要上傳客戶設計檔、機密資料或未檢查的支援包。** 無法安全移除敏感內容時，只寄已去識別的重現步驟，另洽支援方式。</p>
